# سلكاوي أجرة — نسخة المسافة التلقائية
ارفع `index.html` إلى جذر مستودع GitHub ثم فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).

تحدد النسخة إحداثيات العناوين عبر Nominatim (OpenStreetMap) وتحسب مسار القيادة عبر OSRM demo server. تحتاج اتصال إنترنت. هذه خدمات عامة تجريبية ولها حدود استخدام؛ قبل الإطلاق العام أو التجاري استبدلها بمزود خرائط/مسارات مناسب وراجع شروطه. الأجرة مجرد تقدير تجريبي وليست تعريفة رسمية.
